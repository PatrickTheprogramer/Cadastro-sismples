# Sistema de Cadastro de Usuários

Projeto desenvolvido em Python para praticar lógica de programação, Programação Orientada a Objetos (POO) e organização de código.

## Funcionalidades

- Cadastrar usuários.
- Impedir nomes de usuário duplicados.
- Impedir e-mails duplicados.
- Listar usuários cadastrados.
- Buscar usuários pelo nome.
- Menu interativo pelo terminal.

## Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- Git e GitHub

## Estrutura do projeto

```text
sistema-cadastro/
├── main.py
├── usuario.py
├── README.md
└── .gitignore
```

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python main.py
```

No Windows, também é possível utilizar `py main.py`.

## Observações

Os dados são armazenados apenas na memória durante a execução do programa. Ao encerrar o sistema, os cadastros são perdidos.

## Objetivo

Projeto de estudo com foco no desenvolvimento de habilidades em Python e na construção de um portfólio para a área de tecnologia.
